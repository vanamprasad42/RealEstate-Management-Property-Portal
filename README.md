# RealEstate Management & Property Portal

## Simple Project Overview
This project is a modern web application built for listing, discovering, and managing real estate properties across multiple cities. It provides a seamless experience for buyers to view property details and contact sellers, while giving vendors and administrators full control over property listings and user management.

## Key Features
- **Property Search & Browsing:** Filter and view properties by location, city, and property details.
- **Role-Based Access Control:**
  - **Users/Buyers:** Browse listings, view details, send inquiries, and manage accounts.
  - **Vendors:** Add, update, and manage property listings and respond to inquiries.
  - **Admin:** Oversee users, cities, property listings, and manage system settings.
- **Authentication & Security:** User registration, login, JWT authentication, and password reset capability.
- **Media & Inquiry Management:** Image uploads for property listings and built-in inquiry communication.

## Tech Stack
- **Frontend:** React, Redux Toolkit, React Router, Tailwind CSS, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (via Mongoose)
- **Authentication & Utilities:** JWT, bcryptjs, Multer (file uploads), Nodemailer
